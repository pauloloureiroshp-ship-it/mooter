# .ai/ — Multi-agent setup do Mooter.ai

Pasta de configuração e documentação do fluxo multi-agente (Claude Code, Codex,
Gemini CLI) usado no desenvolvimento do Mooter.ai. Nada aqui é código de produto.

| Ficheiro | O que é |
|---|---|
| `GEMINI_SETUP.md` | Como iniciar o Gemini CLI no VS Code + primeiro prompt |
| `AGENT_WORKFLOW.md` | Papéis e regras de colaboração entre os três agentes |

Contexto de cada agente vive na raiz: `CLAUDE.md`, `GEMINI.md`, `AGENTS.md` (cross-tool).
Handoffs entre agentes: `docs/AGENT_HANDOFF.md` e `_handoff/` (waves).
