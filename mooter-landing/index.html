      05 / Install

      Live in 60 seconds.

      One command. Zero admin. Zero sudo. Works with your existing Claude Code install, subscriptions, and local models.

      Step 01 · 60 sec
      One command, any OS
      Detects your OS, installs to ~/.local/bin/mooter, no admin required. Same path on Mac, Linux, and Windows.
      curl -fsSL https://mooter.ai/install.sh | bash
      irm https://mooter.ai/install.ps1 | iex
      Step 02 · 5 sec
      Verify
      Runs 10 health checks (Claude Code, Node, Ollama, hooks, API key, telemetry). Every failure ships a fix command.
      mooter doctor
      Step 03 · start saving
      Just type mooter
      In any project, from any terminal. Launches Claude Code with routing active. The statusline tracks every decision.
      mooter
