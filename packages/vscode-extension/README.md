# 🐮 Mooter — Cost Cockpit for Claude Code

Your Claude Code already has a cost tracker. **Mooter is the autopilot that lowers the bill** — and this extension is its cockpit.

- **Live savings** — real $ vs the all-Opus counterfactual, from your own routing decisions
- **Decisions feed** — every prompt's tier (T0 local → T3 Opus), model, confidence, and *why*
- **One-click sessions** — launch Claude Code with mooter hints active
- **Doctor** — engine, tracker and pipeline health at a glance

Requires the [mooter engine](https://mooter.ai) (`npx @mooter/cli`) and pairs with the official Claude Code extension. Read-only: this extension never routes, never touches your code. MIT. Not affiliated with Anthropic.
