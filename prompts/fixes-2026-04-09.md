## FIX L3 — inject_context.js chama onboarding automaticamente

### Ficheiro: `tools/router/inject_context.js`

Adicionar no início do ficheiro, **depois dos `require()` e antes de qualquer lógica**:

```javascript
// ── Onboarding check (v0.9.2) ─────────────────────────────────────────────
// Se hw-capability.json ou subscription-profile.json estão ausentes,
// corre onboarding.js de forma síncrona antes de classificar.
// Só corre uma vez por instalação. Silencioso se onboarding.js não existe.
const HW_CAP_PATH   = path.join(ROUTER_DIR, 'hw-capability.json');
const SUB_PROF_PATH = path.join(ROUTER_DIR, 'subscription-profile.json');

if (!fs.existsSync(HW_CAP_PATH) || !fs.existsSync(SUB_PROF_PATH)) {
  const onboardingPath = path.join(ROUTER_DIR, 'onboarding.js');
  if (fs.existsSync(onboardingPath)) {
    spawnSync(process.execPath, [onboardingPath], { stdio: 'inherit' });
  }
}
// ─────────────────────────────────────────────────────────────────────────
```

**Dependências**: `path`, `fs`, `spawnSync` do `child_process` — todos já importados em inject_context.js. Verificar que `ROUTER_DIR` está definido antes deste bloco (já está — é `path.join(os.homedir(), '.claude', 'tools', 'router')`).

**Teste de verificação**:

## FIX L4 — backtest.js chama hub-push após --export-delta

### Ficheiro: `tools/router/backtest.js`

No final do bloco que processa `--export-delta`, **depois de escrever o ficheiro delta**, adicionar:

```javascript
// ── Auto-push to frugal-hub (v0.9.2) ──────────────────────────────────────
// Fire-and-forget: não bloqueia nem falha se hub offline.
// Só corre se --export-delta foi explicitamente pedido.
if (args.includes('--export-delta')) {
  const hubPushPath = path.join(ROUTER_DIR, 'hub-push.js');
  if (fs.existsSync(hubPushPath)) {
    const child = spawn(process.execPath, [hubPushPath, deltaOutputPath], {
      detached: true,
      stdio: 'ignore',
    });
    child.unref(); // não bloqueia o processo pai
    console.log('[backtest] delta queued for hub-push (background)');
  }
}
// ─────────────────────────────────────────────────────────────────────────
```

**Nota**: `deltaOutputPath` é o caminho do ficheiro gerado pelo `--export-delta`. Verificar o nome da variável no backtest.js actual — pode ser `DELTA_PATH`, `outputPath`, ou similar. Usar o nome correcto.

**Teste de verificação**:
```bash
node ~/.claude/tools/router/backtest.js --export-delta --dry-run
# → deve aparecer: "[backtest] delta queued for hub-push (background)"
# → o hub-push.js vai tentar POST ao hub (vai falhar silenciosamente enquanto L1 não estiver feito — ok)
```

## FIX L1 — Deploy frugal-hub (Cloudflare Worker + D1 + R2)

> **Pré-requisito**: conta Cloudflare com Wrangler autenticado. Se ainda não tens, correr `wrangler auth login` primeiro.

### Passo 1 — Criar D1 database

```bash
cd ~/frugal/hub
wrangler d1 create frugal-hub
```

Output esperado:

### Passo 2 — Criar R2 bucket

```bash

```

### Passo 3 — Executar migrations D1

```bash

```

Se `001_init.sql` não existir ou estiver vazio, criar com:

```sql
-- hub/migrations/001_init.sql
CREATE TABLE IF NOT EXISTS deltas (
  id            TEXT PRIMARY KEY,
  received_at   TEXT NOT NULL,
  expires_at    TEXT NOT NULL,
  hw_tier       TEXT NOT NULL,
  sub_profile   TEXT NOT NULL,
  lang          TEXT NOT NULL DEFAULT 'unknown',
  session_count INTEGER,
  prompt_count  INTEGER,
  tier_distribution TEXT,
  keyword_signals   TEXT,
  unknown_models    TEXT,
  feedback_signals  TEXT,
  delta_version     TEXT DEFAULT '2',
  trust_score       REAL DEFAULT 0.5
);

CREATE TABLE IF NOT EXISTS model_signals (
  model_name    TEXT PRIMARY KEY,
  first_seen    TEXT NOT NULL,
  last_seen     TEXT NOT NULL,
  mention_count INTEGER DEFAULT 1,
  hw_tiers      TEXT,
  status        TEXT DEFAULT 'pending',
  paulo_notified INTEGER DEFAULT 0,
  notes         TEXT
);

CREATE TABLE IF NOT EXISTS aggregated_stats (
  period        TEXT NOT NULL,
  period_start  TEXT NOT NULL,
  hw_tier       TEXT NOT NULL,
  sub_profile   TEXT NOT NULL,
  sample_count  INTEGER,
  avg_t0_rate   REAL,
  avg_t2_rate   REAL,
  avg_t3_rate   REAL,
  avg_savings   REAL,
  avg_followup  REAL,
  PRIMARY KEY (period, period_start, hw_tier, sub_profile)
);

CREATE TABLE IF NOT EXISTS anomalies (
  id            TEXT PRIMARY KEY,
  detected_at   TEXT NOT NULL,
  type          TEXT NOT NULL,
  severity      TEXT NOT NULL,
  description   TEXT NOT NULL,
  payload       TEXT,
  paulo_notified INTEGER DEFAULT 0,
  resolved      INTEGER DEFAULT 0
);
```
