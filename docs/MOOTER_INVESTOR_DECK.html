How It Works

Zero-proxy architecture. The router emits hints that the AI assistant honours voluntarily. If Mooter dies, everything still works.

USER types prompt in Claude Code | v HOOK (UserPromptSubmit) → inject_context.js (2ms overhead) | v CLASSIFY → 11-pass regex pipeline (<50ms, $0 cost) Pass 1: SHA-256 cache lookup (30-min TTL) Pass 2: Project context enrichment (CLAUDE.md) Pass 3: User override detection ("@opus", "usa sonnet") Pass 4: Fast paths (bash paste, read intent, commit msg) Pass 5: Main scoring (HIGH/MED/LOW/TRIVIAL pattern matching) Pass 6: Low-risk demotion (simple task + risk keyword in content) Pass 7: Quality intent promotion ("pensa bem", "think hard") Pass 8: Low-confidence escalation (confidence <0.5 + risk signals) Pass 9: Auto-learned TUNED_PROMOTE / TUNED_DEMOTE Pass 10: Budget cap enforcement (per-user monthly limit) Pass 11: Provider degradation (no API key → fallback to T0) | v EMIT <router-hint> with tier, confidence, reasoning | v CLAUDE CODE reads hint + CLAUDE.md doctrine → decides: inline | spawn subagent | v LOG → decisions.log (JSONL) → daily backtest → auto-tuning loop

Quality Assurance Stack

  • 84 gold labels — hand-curated test set with expected tier + category
  • 60-prompt validation set — canonical + adversarial + historical prompts
  • 89 automated tests — unit, integration, stress, idempotency, latency
  • Shadow mode — runs classifier in parallel, tracks real-world misroutes
  • A/B testing engine — pits models head-to-head with LLM judge
  • Pre-degradation accuracy — measures classifier quality, not infrastructure
  • Meta-prompt filter — removes tester's own instructions from data

Safety & Privacy

Non-negotiable guardrails. User code never leaves the machine. Critical operations always get premium intelligence.

Dual-Enforce Guardrails

Critical safety rules enforced at two layers:

  • Runtime: classify.js blocks demotion when HIGH_RISK signals fire
  • Upstream: backtest.js filters HIGH_RISK prompts from auto-tuning candidates

Result: even if the auto-learning loop tries to demote a deploy/migration, both layers block it independently.

Privacy-First Architecture

  • Code never sent externally — classification is pure local regex
  • Only 200-char truncated previews stored locally
  • Hub receives only anonymised aggregates (tier distribution, hw_tier)
  • 12 PII regex rules scrub sensitive data before logging
  • User can purge all data instantly

Technical Differentiators

8 innovations that make Mooter unique in the market.

1. Zero-Proxy Design

Router emits hints, never intercepts. If Mooter dies, Claude Code still works normally. No single point of failure.

2. Zero-Cost Classification

Pure regex in <50ms. No LLM call for routing. 114+ patterns in 4 risk categories. Fully explainable.

3. Doctrine-Driven

165-line Markdown file is the contract. Versionable, self-documenting, LLM-native. No parser needed.

4. Hardware-Aware Routing

Detects GPU (NVIDIA/Apple/AMD), selects optimal local model. 5 T0 sub-specialists by content type.

5. Autonomous Self-Improvement

24/7 tester + daily backtest + delta review = system improves without human intervention.

6. Per-User Adaptation

Learns from user's hardware, budget, subscriptions, and prompt patterns. Not one-size-fits-all.

7. Prompt Optimisation

5 strategies transform prompts before models receive them. 56% of prompts optimisable, ~1,000 tokens saved each.

8. Community Flywheel

Anonymised deltas feed hub, hub sends back improved tuning for everyone. Federated learning without data exposure.
