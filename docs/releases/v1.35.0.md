# mooter v1.35.0 — first public release notes

> Draft para o primeiro GitHub Release (gh release create v1.35.0 -F docs/releases/v1.35.0.md). 54 waves até aqui; daqui em diante, release notes públicas a cada wave.

## Highlights
- **Two-axis routing**: complexity → tier (T0 local / T1 Haiku / T2 Sonnet / T3 Opus) + domain → Moo Packs
- **Hook, not proxy** — never intercepts your API traffic; injects a routing hint via Claude Code's own UserPromptSubmit
- **47% saved vs all-Opus** across 658 routed calls (author's machine, methodology published — including where mooter LOSES)
- **Risk floor**: disguised-destructive prompts ("drop legacy_users, nothing reads it") caught at 70% and floored to Opus
- **Self-audit**: mooter audited its own codebase — $2.04 vs $11.78 all-Opus (82.7% saved)
- classify.js unchanged for 19 waves — the routing core is frozen by doctrine; everything around it evolves

## Install
```bash
npx @mooter/cli        # or: curl -fsSL https://mooter.ai/install.sh | bash
```

## Known limitations (honest section)
- General-purpose routing (non-coding prompts): Pareto-dominated on RouterBench — mooter is a Claude Code specialist, not a general router
- T1 tier under-used (dead zone identified in benchmark; tuning tracked)
- Windows: PowerShell installer in beta
