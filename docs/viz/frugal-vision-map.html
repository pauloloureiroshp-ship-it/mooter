O que acontece em < 50 ms quando escreves um prompt
Cada turn passa por 8 etapas antes de o modelo responder. Tudo automático, invisível, sem latência perceptível.

Budget Engine — o coração do equilíbrio perfeito
O utilizador define o orçamento. O Frugal descobre o hardware e as subscriptions. O Budget Engine calcula a configuração óptima — e mantém-na automaticamente.
North Star do produto: A maioria dos vibe coders não sabe o que tem (hardware), o que já paga (subscriptions), ou quanto quer gastar. O Frugal descobre tudo por eles e apresenta: "aqui está o teu equilíbrio perfeito."

Flywheel de Aprendizagem — como o Frugal fica melhor sozinho
Cada decisão de routing alimenta o sistema. Cada utilizador melhora a experiência de todos os outros.
1

🖊 Utilizador escreve prompt

Cada sessão gera 10-50 decisões de routing. Cada decisão é registada em decisions.log com tier, categoria, confiança, latência, e modelo usado.

2

⚡ Classify < 50ms — enriquece o log

classify.js devolve tier + sub_category + confidence + reasoning. gsd-turn-end.js persiste no log com timestamp e prompt_hash (SHA-256, sem conteúdo).

3

📊 decisions.log cresce

Actualmente: 663 decisões. Com Friends Beta: 5-10× mais por semana. O log é a única fonte de verdade — tudo deriva dele.

4

🌐 Hub agrega deltas anónimos

hub-submit-events.js envia deltas (sem conteúdo, só fingerprints) para Cloudflare D1. O hub agrega por perfil: hardware + budget_tier + subscription_tier.

5

🔧 Tuning gerado e distribuído

Cron diário: hub agrega → gera router-tuning-latest.json → guarda em R2. hub-pull.js (cooldown 4h) faz download para cada utilizador.

6

✅ Router fica melhor para todos

update-router.js aplica o TUNED-BLOCK no classify.js local. A melhoria de 1 utilizador com RTX 4090 beneficia todos com o mesmo perfil de hardware.

Três loops de aprendizagem

🔁 Loop Local (nocturno)

Frequência: 02:00 todos os dias
Actors: backtest.js → update-router.js
Aprende: padrões do TU próprio
Output: TUNED-BLOCK no classify.js

🌐 Loop Comunitário (diário)

Frequência: Daily cron no Cloudflare
Actors: hub D1 → R2 → hub-pull
Aprende: padrões de todos os utilizadores
Output: router-tuning-latest.json

⭐ Loop de Qualidade (manual)

Frequência: após cada T2/T3
Actors: /frugal-rate → feedback-collector.js
Aprende: outcome quality, não só custo
Output: followup_quality no log
