# VSCODE_SETUP.md — VS Code with frugal

## Batch install — all recommended extensions

```bash
code --install-extension anthropic.claude-code \
     --install-extension usernamehw.errorlens \
     --install-extension eamodio.gitlens \
     --install-extension aaron-bond.better-comments \
     --install-extension bradlc.vscode-tailwindcss \
     --install-extension esbenp.prettier-vscode \
     --install-extension dbaeumer.vscode-eslint
```

---

## Extension guide

**anthropic.claude-code** — The foundation. Surfaces frugal routing tier in status bar, enables inline diffs, plan review, @-mentions.

**usernamehw.errorlens** — Shows errors inline. When Opus finds issues, ErrorLens makes them immediately visible.

**eamodio.gitlens** — Enriches git context. Powers `@git:HEAD~3` mentions in Claude Code.

**aaron-bond.better-comments** — Colour-codes `// ARCH:`, `// REVIEW:`, `// TODO:`, `// FIXME:` comments added by frugal subagents.

**bradlc.vscode-tailwindcss** — Validates Tailwind classes generated by local-transformer (Ollama).

**esbenp.prettier-vscode** — Format-on-save. Keeps code clean without routing saves to Claude.

**dbaeumer.vscode-eslint** — Pre-analysis before Claude. Shorter, cheaper prompts.
