# Request access to mooter

`mooter` is in **private friends-beta** while we validate it in real production usage.
The repository is private; the install scripts at https://mooter.ai work but require an invite to clone the source.

## How to request access

**Option A — landing (preferred):** sign in at <https://mooter.ai> with GitHub. You'll be added to the waitlist and Paulo reviews requests weekly.

**Option B — direct email:** drop a two-line note to <paulo.loureiro.shp@gmail.com> with:

1. Your GitHub handle.
2. One line on what you're building / how you use Claude Code today.

That's it. No application form, no questionnaire.

## What you get when invited

- Read access to the private GitHub repo (`pauloloureiroshp-ship-it/frugal`).
- One-command install on macOS / Linux / Windows.
- Telemetry opt-in to help the classifier improve for everyone.

## Why the gate

We're validating the router on real workflows before opening the source publicly. The MIT license stays — you can use, fork, modify — but you need to be let in first while we close the loop on the friends-beta cohort. See [NOTICE.md](NOTICE.md) for the full rationale.
