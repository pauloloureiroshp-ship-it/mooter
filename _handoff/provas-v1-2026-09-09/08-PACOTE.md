## Os oito cartões (inglês, prontos a colar; o texto integral está em cada `slide.md`)

### P1 · Classifying costs no inference — and, on these 40 sampled prompts, the rule is wrong more often than "always T2"
0 inference tokens, 0 external hosts to classify (in-process http/https/fetch wrappers on 1,176 classifications; the socket tap of that run recorded only 270 tap-loaded events and no connection records — it logged only on socket close and does not establish absence of connections). Rule 0.002 ms median in-process; **the hook is not free: 207 ms median / 1,272 ms p95**, ~870 bytes of hint per prompt, local pre-answer timed out 75/75. Accuracy vs blind labels, **on the 63 out-of-training prompts the protocol pre-registered as the principal test**: rule **22.2 % [13.7, 33.9]**, local 14B judge **69.8 % [57.6, 79.8]**, constant T2 65.1 %; McNemar one-sided judge > rule **p = 3.0 × 10⁻⁷**. Split by stratum, because the protocol required it: on the **40** diverse real prompts rule 35.0 % [22.1, 50.5] vs judge 52.5 % [37.5, 67.1] vs constant 45.0 %, p = 0.059; on the **23** R-24 prompts — one template with the task swapped, so close to a single observation — rule **0/23** against judge **23/23**. The 63-item p-value is inflated by that pseudo-replication and the 40-item one is honest about a small sample; **neither favours the rule**, and earlier versions of this card printed only the friendlier of the two. Training set 88.6 % vs 82.9 % vs 14.3 %. Kappa between label engines 0.50. The rule predicts T0 on 31 of the 40; 13 of those are T2/T3 for both label engines. The 40 are dated 2026-08-01 → 2026-09-04 (34 August, 6 September). tzachbon abstains 63/63; ccr/LiteLLM have no classifier (n/d). *Does not prove: commercial value; obedience; > 500 chars; that the blind label is truth; the keyed/arbiter configuration.*
