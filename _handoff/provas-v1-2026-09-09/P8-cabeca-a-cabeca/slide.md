**Wins by construction (as measured here, no key, D1):** classifying recorded no external destination in the tapped Node processes and costs 0 inference tokens (the hook's local pre-answer is a separate step and does spend local GPU tokens); a $0 local tier is reachable by rule, where LiteLLM's cost routing selected the zero-priced deployment 0/40 times. **Read that win next to the loss two rows up, because they are the same behaviour.** “Reachable by rule” is the rule saying T0. P1 measured that same rule saying T0 on 31 of 40 real prompts, 13 of which both label engines put at T2/T3 — the card’s principal failure. P2 measured what the reachable free tier is worth once you get there: the local model solved 7/20. So the honest sentence is that the rule reaches the free tier **easily and too often**, and this table prints both halves rather than only the flattering one. **Not established:** that a critic in a different engine catches more — 26/28 vs 27/28, p = 1.0 both ways. This is a printed loss for the pre-registered hypothesis, **not a tie**: equivalence is not claimed and no margin was pre-defined. Calling it a tie would reintroduce the exact claim P4's adversary killed. **Losses, printed:** the rule's accuracy on real prompts; executed obedience 0/20; the cost line is not in the product; the arbiter would ship the raw prompt; the hook is not free (207 ms).
