# Slide P8 · Nine things measured on one machine, side by side — and what each column is actually entitled to say

**Read this line before the table.** This is **not** a head-to-head benchmark. The rows come from different proofs, different corpora, different configurations and different runs; the tools were not put through one common harness. An adversary in a different engine attacked it cell by cell and found four fatal framings in the first version — including numbers from a **key-present** configuration printed under a **no-key** heading. This version prints the configuration next to each number instead of at the top, and the "wins by construction" summary has been removed, because the comparisons that summary rested on were not like-for-like.

**Legend:** `n/d` = not measured here, with the reason beside it. `n/a` = the operation does not exist by definition in that system (the pre-registered rule in `protocol.json`). Neither ever means "does not have": these tools were not given an adapter for this benchmark, which is a fact about this run, not about them.

**Corpus and setup:** 63 out-of-training prompts (P1: 40 real, dated 2026-08-01 → 2026-09-04, plus the 23 R-24 task prompts), 20 of the 40 for P5, 20 synthetic tasks (P2), 28 planted mutants (P4), 23 real repository tasks (P7). One Windows 11 machine with an RTX 4090. A live budget-cap defect (**D1**) floors the router at T0 in most of this work. Competitors installed in isolation from their published packages¹⁻⁴.

**What survives as a comparison, and it is narrow.** Two things were measured on the same corpus in both columns: **tzachbon abstains on 63/63 of these Portuguese prompts** where the rule emits a tier for all 63, and **LiteLLM's cost routing did not select the zero-priced deployment in 40 attempts** where the rule emits T0 by default. Neither is a like-for-like contest: the rule emits a *label*, LiteLLM performs a *routing decision*, and P3 measured **zero** executed local delegations. Calling the label a win over the routing would be a tautology, and it has been removed from this card.

**Losses, printed with the same typography.** The rule's agreement with a blind label on out-of-training prompts is **22.2 %** where a local 14B judge reaches 69.8 %. Executed local delegation is **0/20** by the attribution method used. The cost line with per-event origin is **0 of 1,451** in the live ledger and the module that reaches 156/156 is not shipped. With a key present, the arbiter builds a request carrying the whole prompt. The hook costs **207 ms** at the median. The pre-registered "a critic in a different engine catches more" was **not supported**. And the one advantage this package does measure — the P7 timing result — arrived after a broken stopping rule and is published without confirmatory status.

**What no cell here claims:** that any competitor lacks a feature; that agreement with a second engine's label is accuracy against ground truth; that socket destinations reveal content; that a binary test passing means equal quality; or that any of these numbers generalise past this machine, this corpus and this day.
