🔗 Problema Actual — Corpus Count desactualizado
O valor 1,437 prompts no README e docs é uma snapshot manual de 2026-04-09. Desde então correram muitas mais sessões e o decisions.log cresceu — mas os MDs não actualizam automaticamente.

Solução: update-metrics.js — script que corre após cada backtest, conta as linhas reais do decisions.log, calcula accuracy actual, e escreve metrics-snapshot.json. Um segundo passo actualiza os badges no README.

🔐 Garantias de Privacidade — o que NUNCA sai da máquina
Nunca enviado:
O texto dos prompts · código-fonte de qualquer ficheiro · nomes de ficheiros · paths locais · API keys ou secrets · prompt_preview (80 chars) · qualquer PII
Enviado anonimizado:
tier (T0/T1/T2/T3) · confidence (0-1) · prompt_len (número) · hw_tier (gpu_high/mid/cpu) · cascade_path (sequência de tiers) · frugal_version · session_hash (anónimo)
Flywheel Comunitário
O efeito de rede que torna o frugal progressivamente melhor com mais utilizadores
Mais utilizadores → melhor algoritmo → mais savings → mais utilizadores
O código é MIT. Qualquer um replica em 2 semanas. O que não replica: os dados acumulados.
01
Utilizador instala frugal
1 linha bash/ps1. Vê savings em 30 segundos. /frugal-status confirma que funciona. Primeira impressão: "isto funciona mesmo."
02
Router aprende os padrões locais
decisions.log cresce. Backtest diário às 02:00. TUNED block ajusta-se ao estilo de prompting do utilizador. Savings aumentam ao longo do tempo.
03
Delta anonimizado vai para o hub
event-builder.js remove tudo que identifica. Só sinais de routing. hub-submit-events.js envia. O utilizador contribui sem saber que está a contribuir.
04
Hub agrega e gera tuning comunitário
Cron diário analisa deltas de N utilizadores. Produz router-tuning-latest.json melhor que qualquer tuning individual. Sobe para R2.
05
Cada utilizador recebe a melhoria
hub-pull.js descarrega router-tuning comunitário. classify.js de cada instância fica mais preciso. Savings da comunidade sobem.
06
Savings visíveis → boca-a-boca
Landing mostra savings reais da comunidade (live counter). Utilizador recomenda. Novo utilizador instala. Flywheel accelera.
